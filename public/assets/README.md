# WRTS Web Assets

## Official brand assets
The application expects these production files:
- `public/assets/brand/wrts-primary-logo.webp` — primary circular lion / WE RUN THESE STREETZ mark
- `public/assets/brand/wrts-wordmark.webp` — compact WRTS wordmark

Source artwork was supplied by WRTS on 24 September 2026. Do not redraw, recolor, stretch, rotate, add effects to, or substitute either mark.

## Official web palette
- WRTS Royal Blue: `#0B14C7`
- WRTS Indigo: `#110EA1`
- Deep Blue: `#050B54`
- Black: `#000000`
- White: `#FFFFFF`
- Ice Blue: `#C8D7FF`

Black, white and WRTS blue should dominate. Supporting blue values are for hierarchy, gradients and accessibility—not competing campaign identities.

## Photography
Photo assets remain under `public/assets/photos/`. Photography should feel candid, energetic, community-centered and contemporary. Avoid generic race-only imagery because WRTS represents movement across Wellness, Wealth, Wisdom and Work.
