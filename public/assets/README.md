## Photography standard
Use the existing werunthesestreetz.com visual language as the reference:
- real community over generic stock fitness
- movement, connection and environment
- candid/editorial over posed corporate imagery
- diverse ages and participation styles
- visible neighborhood/street context when useful
- enough negative space for WRTS typography and overlays
- strong contrast and natural energy
- avoid images that make WRTS appear to be only a race organizer
